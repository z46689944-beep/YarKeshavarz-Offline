# یار کشاورز — نسخه آفلاین 📱

این مخزن نسخه مستقل آفلاین یار کشاورز است.

- بدون Cloudflare Worker
- بدون OpenAI API و API Key
- دستیار آفلاین و پایگاه دانش کشاورزی
- ثبت زمین، هزینه، درآمد، انبار و ادوات روی همین دستگاه
- اندازه‌گیری آفلاین با لمس صفحه و GPS
- آب‌وهوای این نسخه داده نمونه محلی است و زنده نیست
- Service Worker مستقل با کش جداگانه
- پنل مدیریت محلی و بازیابی رمز مدیریت

نسخه آنلاین در Repository جداگانه `YarKeshavarz` نگهداری می‌شود.
